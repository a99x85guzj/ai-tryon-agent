# AI 虚拟试衣 Agent

## 阶段五：前后端端到端手动测试

1. 在项目根目录复制 `.env.example` 为 `.env`，填写所需 API Key，然后执行 `uv run python sync_env.py`。
2. 启动单 worker 后端：`uv run uvicorn backend.main:app --host 127.0.0.1 --port 8000 --workers 1`。
3. 新开终端进入 `frontend`，执行 `npm install` 和 `npm run dev`，浏览器打开 `http://localhost:5173`。
4. 分别拖入服装图与可选模特图，确认界面显示“图片符合要求”；再选择服装部位、模式、场景、角度和变体数量。
5. 提交任务，观察“分析服装 → 等待确认 → 生成产物”的 SSE 进度。确认卡出现后选择候选模特、编辑提示词，再批准或提交修改。
6. 生成过程中检查“取消任务”按钮；任务完成后检查图片参数标签、单张下载和 ZIP 批量下载。
7. 失败场景可上传不支持的文件或停止后端，确认页面显示中文提示且不会白屏。

## 阶段六：拖拽微调手动测试

1. 完成一次包含至少 2 张结果图的生成任务，点击任一结果图进入编辑模式。
2. 等待上装、下装 bbox 出现，拖动或缩放框；也可点击“手动画框”重新框选。
3. 输入“换成红色百褶裙”或上传替换服装图，选择上装/下装后确认替换。
4. 勾选“同步应用到其他变体”，验证所有结果原位刷新；用撤销/重做检查编辑历史。
5. 选择 2–4 张成品并生成展示视频，确认任务完成后可在编辑区播放。
6. 无真实 Key 时执行 `uv run python tests/smoke_phase6.py`，演示 bbox、同步替换、刷新和视频完整 mock 链路。
